# Ops Center — public mobile viewer

Read-only public summary of user-owned projects, scheduled jobs and known service links.

This GitHub Pages site is intentionally public and unauthenticated. Only sanitized summaries are committed; original scripts, private paths, notes, logs, credentials, internal URLs and admin controls are NOT published.

The site remains accessible if the source PC is offline. The data snapshot updates only while the connected PC and its scheduled publisher are available.

Local-only apps are marked PC-only and are not remotely exposed.
